Three files do the job of pom.xml / pyproject.toml. Open each one; they are short.

One real story from setting up this repo. The newest TypeScript (7) crashed our lint layer, because the lint plugin only supports versions below 6.1. We pinned 6.0. In this ecosystem the compiler, the linter and the runtime are three separate projects on three release schedules; in Java they ship together. Expect version pinning to be part of the job.

Recall first

Look away. Say the eight ideas out loud, and for each one the thing Java or Python does differently. Then check.

Check yourself

Values and inference (one number) · structural typing · unions and narrowing · functions and inferred generics · types vanish at runtime, so validate at boundaries · null vs undefined, ?. and ?? · modules, .ts extension, import type · promises on a single thread.

Then test it

Seven questions. Options are shuffled each visit.

1. A request body is cast with as CreateOrg, but the client sent {"name": 42}. What happens?

Types are erased; as checks nothing. Only runtime code (our Zod contracts) can reject it, which is why every boundary parses.

2. class Dog { name = "" } and function greet(x: { name: string }). Does greet({ name: "Rex" }) compile?

Structural typing. Names and declarations do not matter; shapes do.

3. Why does this repo use "queued" | "running" instead of an enum?

We run source directly. Anything that is not pure type syntax cannot be erased, so Node refuses it.

4. const gap = props.gap || 16 and the designer set gap to 0. What is gap?

|| falls through on every falsy value, including 0 and "". ?? falls through only on null and undefined.

5. Two independent 50 ms database calls, each awaited on its own line. Total wait?

Each await finishes before the next line starts. Promise.all overlaps the waits.

6. A handler runs a 3-second synchronous loop. What do other connected clients experience?

One thread runs all your JavaScript. While it is busy, no timer fires, no socket is read, no heartbeat is answered.

7. You add a fifth op type to the union and forget one switch. When do you find out?

The exhaustiveness check turns "I forgot a case" into a type error in every switch that matters.
